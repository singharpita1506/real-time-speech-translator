# Real-Time Speech Translator

## Overview
A Python-based application that translates spoken language into another language in real time. The application captures speech through a microphone, converts it into text, translates it into the selected language, and converts the translated text back into speech.

## Features
- Real-time speech-to-text conversion
- Multi-language translation
- Text-to-speech output
- Support for English, Hindi, Telugu, Tamil, Marathi, Gujarati, Punjabi, French, and Spanish

## Technologies Used
- Python
- SpeechRecognition
- deep-translator
- gTTS
- playsound

## How It Works
1. Select the input language.
2. Select the output language.
3. Speak into the microphone.
4. The application converts speech to text.
5. The text is translated into the selected language.
6. The translated text is spoken aloud.
